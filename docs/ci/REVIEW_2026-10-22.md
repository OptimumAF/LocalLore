```powershell

```

Result: 13 tests passed. Review covered first-failure propagation, interruption,
missing tools, invalid CLI arguments, argument transport through paths containing
spaces/apostrophes, root resolution, lock/offline options and rejecting modified
Gradle bootstrap code/settings before launching Java. Calls use argument arrays
with `shell=False`; checks do not provision tools or accept licenses. Java 17 is
a prerequisite selected by the environment; the runner does not claim a separate
JDK version certification.

The APK audit requires `ANDROID_HOME` or `ANDROID_SDK_ROOT`, even if Gradle can
build using an existing `local.properties`. That explicit requirement prevents
the audit from silently guessing a different SDK. The workflow supplies
`ANDROID_HOME` through its hosted image. The runner invokes Android's pinned
Build-tools 35.0.0 executable with an argument array.
