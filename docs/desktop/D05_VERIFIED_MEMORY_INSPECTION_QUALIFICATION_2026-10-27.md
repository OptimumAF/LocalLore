## Implemented boundary

Story Lab exposes verified extractive packet metadata, entries and original
source events for a saved Domain 1 story with the explicit Player lens and an
existing native Lab grant. Character and Omniscient lenses cannot read these
Player packets; even a character whose ID equals the native player ID receives
no Player grant. Domain 2 packet inspection is explicitly unavailable.

The mounted panel uses Main's actual `MemoryInspectionController` and native
`memory_inspection` command. Rust owns the selected session/scope/head, Player
permission, coherent snapshot, coverage recheck, binding, cursor, source membership,
Query2 result, output bounds and cancellation. A source match requires the actual
Query2 event at its original scope and sequence, read at the retained packet's
through revision. The frontend checks that returned page rather than constructing
a substitute. A verified prefix below the current head shows its raw delta;
missing or rejected cache content does not become a packet or a semantic summary.

Reads do not admit/step/prune memory jobs, grant knowledge, generate text or write
canonical events. The native UI test separately uses existing explicit consent,
admission and step controls to build a real packet. Inspecting it grants nothing
to NPCs or generation. The new controller retires pending presentation on context
changes; it adds no native per-read cancellation command or cleanup authority.

## Reproduce

Environment: Windows NT 10.0.26300 x64; Rust/Cargo 1.93.1; Node 24.22.1;
TypeScript 7.0.2; React 19.3.1; Tauri 2.12.5. Existing locked packages were used
offline, with no dependency/model upgrade or model download. Use the task's
existing isolated Cargo cache, temporary directory and native target. Only one
heavy frontend/Cargo/native process runs at a time; keep the source committed,
clean and unchanged for each command and actual cohort.

From repository root, with `$taskNode` the pinned local Node executable and
`$ownedTarget` an existing isolated native target:

```powershell
$env:CARGO_HOME = '<existing isolated locked-package cache>'
$env:CARGO_BUILD_JOBS = '1'
$env:CARGO_INCREMENTAL = '0'
$env:CARGO_PROFILE_DEV_DEBUG = '0'
$env:CARGO_PROFILE_TEST_DEBUG = '0'
$env:LIBSQLITE3_FLAGS = ''
& $taskNode apps/desktop/verify-frontend.mjs
cargo test -p locallore-workspace --test verified_memory_inspection --all-features --locked --offline --jobs 1 --target-dir $ownedTarget -- --test-threads=1
cargo test -p locallore --test memory_inspection_port_review --all-features --locked --offline --jobs 1 --target-dir $ownedTarget -- --test-threads=1
cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml --features dev-harness --locked --offline --jobs 1 --target-dir $ownedTarget memory_inspection_commands::tests -- --test-threads=1
cargo clippy --manifest-path apps/desktop/src-tauri/Cargo.toml --all-targets --all-features --locked --offline --jobs 1 --target-dir $ownedTarget -- -D warnings
```
