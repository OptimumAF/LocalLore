## Behavior and authority

Story Lab retains the original nine-case deterministic lane and adds a separate
curated library over the **existing** six-story, four-turn curated runner.
Scripted fake and experimental native-model lanes are explicit. The adapter
does not invoke a CLI or construct another evaluator, fixture corpus, context
compiler, memory policy, command interpreter or commit path. Actual provider
output still passes through the existing shared Host/Play/Engine. No fixture,
expected command, role budget, prompt, worker or model was changed here.

`local_lane::desktop_api` exposes catalog, request binding, read-only inspect and
bound evidence. Runner and reader reuse the same checkpoint restoration
validator. Inspect reads an existing lock without creating an invocation,
settling unknown reservations, loading assets, invoking a provider or rewriting
JSON/HTML. Tests compare every run-file byte before and after reads. The stored
historical report remains immutable; current checkpoint coverage is labeled
separately from retained report coverage. A historical source mismatch remains
viewable but cannot resume. Resume compares the entire current compiled basis,
including profile, limits and source. The separately owned prompt 2.3 change
must therefore invalidate old executable resume, rather than rewrite history.

Native `evaluation_curated` admits only closed actions and bounded typed query
fields. It accepts native IDs/tokens, not renderer paths, scripts, SQL, shell,
arbitrary providers or prompts. Runs live in a native-owned sibling
`curated-evaluations` directory; existing deterministic reports are untouched.
Windows pinned handles reject reparses; native canonical paths use the extended
absolute prefix to support the real long test directory. The same evaluation
registration gate, worker ownership and operation IDs cover both lanes.

Each admitted run binds client UUID, native run UUID, lane, selection, original
batch and exact source **before** execution. Repeating the client request
recovers that run; a mismatched request is refused. A lost acknowledgement and
process restart use native durable metadata. Renderer local storage retains only
the pending client UUID. A completed resume is a cache read: no invocation,
model reservation or asset access. A partial resume makes one existing runner
invocation for the chosen batch, not one model reload per case. Native evaluation
holds a ModelManager RAII reservation requiring ordinary Play runtime unloaded;
load, unload, import and competing evaluation cannot race that admission.

Existing cumulative limits remain 32 admitted attempts, 96 charged roles,
30 minutes charged active work and 32 invocations. Unknown interrupted work stays
conservatively reserved. Current-turn/role progress is unavailable; the UI says
so and updates completed checkpoint progress when the bounded invocation returns.
Cancellation can abandon the current four-turn attempt while preserving prior
checkpoints and unknown reservations. Cleanup is cooperative, not hard realtime.
Existing aggregate disk limits cover both libraries: 32 MiB/run, 256 MiB total
and 64 MiB required free space; curated catalog caps at 32 runs. Quotas refuse
new work rather than deleting history. Files remain private locally without an
automatic expiry promise; OS backups and outside copies are separate.

## Evidence boundary

The UI opens only checkpoint-bound case/turn evidence, pinned to native run,
binding, original story/branch, revision and canonical fingerprint. The shared
reader resumes the synthetic case database read-only, selects the actual Engine
revision, verifies the canonical fingerprint, then calls the existing inspection
query. It never imports evaluation state into the live workspace Host.

D05 links are bounded read-only evaluated snapshots (first 32 rows, no pagination
in this adapter). Accepted receipt/diff appears only where actually retained and
permitted. Rejected turns open real state rather than an invented accepted diff;
the receipt section explicitly says none is available. Player inspection receives
neither omniscient receipt nor private role output/metrics. Changing lens,
session, selected case/turn or closing the panel clears/fences late presentation.
Inspection grants no generation knowledge or live character knowledge.

The D06 bridge shows only actual retained raw role outputs, hashes and metrics,
rendered as escaped text. Full historical context, prompts, schema bytes, staged
plans and window traces were not retained by this runner and remain explicitly
unavailable. Exact reconstruction is false. Raw proposal/narrator text is not an
accepted canonical effect. This bridge does not claim full capture consent,
export, deletion or trace-retention functionality for old runner output. Future
native generation requires explicit private-output consent; report opening does
not execute a model. JSON and inert HTML reports remain the existing runner's
outputs. Arbitrary external CLI report import is not implemented; this UI opens
the native-owned library.

## Reproduce locally

Windows x64 10.0.26300.0; Rust/Cargo 1.93.1; Node 24.22.1; pinned frontend
dependencies from the existing dependency directory (no installs/downloads).
Use an isolated local worktree and generated output directories outside Git.
`apps/desktop/node_modules` was an ignored junction to the accepted dependency
cache. No real model, device, emulator, desktop automation or network observation
was used. Application-owned WebView2 CapturePreview rendered the invisible app;
it did not capture the desktop. Delegation slots were occupied; this author's
work was sequential and coordinator review remains independent.

PowerShell setup from repository root (replace the three local directories):

```powershell
$env:TEMP = 'D:/task-output/unique-temp'
$env:TMP = $env:TEMP
$env:CARGO_PROFILE_DEV_DEBUG = '0'
$env:CARGO_PROFILE_TEST_DEBUG = '0'
$env:CARGO_INCREMENTAL = '0'
$evalTarget = 'D:/task-output/eval-target'
$nativeTarget = 'D:/task-output/native-target'
```

Create those task-owned directories first. Run each Rust command in both modes:
without a feature and with `--features local-model` for eval, or
`--features dev-harness` for desktop. Tests used `-- --test-threads=1` for native.

```powershell
cargo +1.93.1 test --manifest-path crates/locallore-eval/Cargo.toml --all-targets --locked --offline --target-dir $evalTarget
cargo +1.93.1 clippy --manifest-path crates/locallore-eval/Cargo.toml --all-targets --locked --offline --target-dir $evalTarget -- -D warnings
cargo +1.93.1 fmt --manifest-path crates/locallore-eval/Cargo.toml -- --check
cargo +1.93.1 test --manifest-path apps/desktop/src-tauri/Cargo.toml --all-targets --locked --offline --target-dir $nativeTarget -- --test-threads=1
cargo +1.93.1 clippy --manifest-path apps/desktop/src-tauri/Cargo.toml --all-targets --locked --offline --target-dir $nativeTarget -- -D warnings
cargo +1.93.1 fmt --manifest-path apps/desktop/src-tauri/Cargo.toml -- --check
git diff --check
```

From `apps/desktop` with Node 24.22.1 on PATH:

```powershell
node verify-frontend.mjs
node node_modules/prettier/bin/prettier.cjs --check 'ui/*.{ts,tsx,html,css}' '*.{json,mjs}'
$env:LOCALLORE_D07_CURATED_ARTIFACT_ROOT = 'D:/task-output/curated-artifacts'
$env:LOCALLORE_D07_TARGET_DIR = $nativeTarget
node curated-harness.mjs
```

The fixed harness builds `dev-harness`, launches only its own invisible app,
uses the same actual frontend controllers/native IPC/runner, retires and reopens
a window, then restarts the process. It admits only fixed synthetic hold/lost-ack
controls under development cfg; normal build verification rejects those hooks.
It creates a fresh UUID artifact folder; never reuse private stories. Rebuild the
normal frontend afterward with `node verify-frontend.mjs` when checking normal
hook exclusion. No arbitrary code/file/shell execution or remote debug server
was added to the app.

## Retained failures and limits

conversion type ambiguity and strict Clippy argument-count findings; normal build,
explicit types and typed request structures fixed them without lint exemptions.
The actual long native test path (257 characters before SQLite sidecar suffix)
failed with Workspace/EvaluationIo; pinning then canonicalizing to Windows extended
paths fixed the identical test without shortening its input or changing Store.
The first native cohort showed old deterministic controls enabled during curated
ownership (native correctly refused Busy); the UI now disables both lanes.

Earlier clean cohorts had 38/13 and 44/14 assertions/images but did not explicitly
retain the initial window's final error gate across reopen. A stronger e700e84
cohort failed because the harness expected the visible error category rather
than ErrorBuffer's existing `Transport` normalization. The gate now requires
exactly one expected transport error, zero later errors. The 4092612 cohort
passed 47/15. Adding the explicit pre-retirement snapshot first failed because
its fixed label was absent from the native allowlist (31a1ebd9 local artifact);
the failed report retained the already-passed error/nonmutation assertions.
772dea8 adds that single fixed label and checkpoint failure-stage labeling; final
51/16 passed. One local command setup attempt was interrupted before a valid
measurement after a working-directory mistake. Failures/logs remain local;
they were not replaced with favorable output or represented as model failures.
