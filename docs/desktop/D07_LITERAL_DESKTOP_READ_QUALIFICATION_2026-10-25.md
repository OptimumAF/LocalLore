## Capability and shared authority

`literal_v3::desktop_api` exposes opaque `OpenedComparison`, `open_read_only`,
`summary` and `evidence`, using the existing V2 reader's closed RowId, Arm, Edge
and EvidenceRequest types. Its summary is transport1/protocol3/report3, with
literal/Relevant descriptors, actual optional evidence and explicit unavailable
execution/UI flags. It does not reconstruct a V2 report or selected protocol1
source. There is no new provider, process owner, persistence schema, context
policy, dependency, IPC, file execution or debug server.

Opening pins the directories and takes a read-only lock on the existing run.lock;
it never creates a missing run/lock. Actual V3 manifest/profile/reference, rows,
Store outcomes, artifact hashes, setup metrics and accounting are validated by
the existing producer reader. The capability retains the validated manifest,
full checkpoints, snapshot and binding. Summary is that frozen validated
snapshot, not a live status or execution grant.

Every evidence read applies the existing access guard before binding, row,
manifest or file probes. Actor raw receipt/capture/output requests are forbidden.
Permitted reads revalidate the exact manifest and selected full checkpoint against
the retained snapshot. A private borrowed EvidenceTurn view then reuses the
same existing evidence renderer. V2 keeps its StoredTurn wrapper and maps each
field directly; the view is neither a wire format nor canonical state authority.

Query evidence reopens actual Store state, verifies before semantic input and
after semantic/mechanical hashes, cuts the immutable Engine at the chosen edge,
then uses actual Query2 with that cut head, no alternate at_revision, limit64
and the requested observer. Receipts come from actual Store and match the
retained receipt hash. Capture, recording and raw outputs are checked from their
bounded retained bytes/hashes. Missing guard/recovered artifacts remain missing.
Inspection never changes character knowledge or what generation may access.

Historical source mismatch permits qualified read-only display, never resume or
execution. Hashes establish fixture identity and consistency, not authenticated
evidence origin. Native lane metadata does not itself prove observed load/roles.
