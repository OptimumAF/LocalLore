Review found malformed UTF-16 input is not yet excluded by validPlayInput. A lone surrogate passes nonblank/control checks and UTF-8 byte counting, but the encoder may replace it before JNI, breaking the exact-original-text contract. [JDK17 String.getBytes(Charset)](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/lang/String.html#getBytes(java.nio.charset.Charset)) specifies replacement of malformed input; the production transport uses this encoding path after JSONObject serialization. Requested correction: reject malformed surrogate sequences or require strict encoding before submission, with lone-high/lone-low rejection and valid supplementary-pair tests at the 2048-byte boundary. This is a source finding, not a reproduced accepted device mutation.

A null local mode denotes the actual free_text Host operation; it does not convert the intent into typed demo actions or silently fall back to another provider. The reviewed correction rejects malformed UTF-16 while allowing valid surrogate pairs. Busy joins Full and other storage/transport uncertainty in retaining pending identity. Cancellation of an unknown original key clears only that same pending operation, and its captured cancelled flag remains set, preventing a later submit continuation from preparing the abandoned request. These corrections address source findings; execution evidence is still pending.

The submission mutex orders only submission against saved cancellation. The finite submit uses NonCancellable so cancelling a Kotlin waiter cannot erase its native acknowledgement and let cancellation race ahead of a subsequently created draft. Cancellation then acquires that same mutex and addresses the original persisted key. Prepare/generation is outside the mutex: native cooperative cancellation and the existing ViewModel generation fence remain responsible for stopping effects and rejecting late publication. Close uses the existing asynchronous transport/native ownership path. This does not claim a hard wall-clock bound for arbitrary noncooperative transports, or that cancelling Kotlin interrupts an already executing JNI call.
