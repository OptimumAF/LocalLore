# Retained-parent archive chooser qualification

Supporting M08.04/M08.06 and M10.02; stacked on draft/unmerged PR #210.
This protocol defines the checks. An executed result requires its own dated
source, artifact, original output and ownership evidence.

The fixed `RetainedArchiveChooserTest` uses the input-process debug product,
the real MainActivity and document pickers, existing NativeArchive APIs and
the deterministic scripted provider. No model weights or phone are involved.
The existing protected chooser fixture provider supplies only synthetic data.
No replacement app gateway, shell permission adoption or SQL fixture is used.

Seed a separate source database through typed Rust APIs: root1, parent P2,
child G forked at2, then parent-only TAIL at3. Retire P through the native
preview/commit path. Export ordinary Domain1 archivev2 at actual source schema5.
Its retained prefix keeps original receipt scopes; TAIL must not transfer.
Create an independent baseline in the product's Context-derived workspace
before launching MainActivity; preserve every previously accepted story.

Exactly two methods are selected:

1. `chooserRoundTripPreservesRetiredParentReceiptsAndReservedIds`: choose the
   synthetic archive through DocumentsUI, inspect the rendered preview and
   require no mutation before explicit Import. Open the imported story and
   select retained G. Compare full eligible native views, original receipt
   scopes, catalog and reserved-ID refusal. Before continuing play, require
   exact native re-export and system CreateDocument output bytes. Check narrow
   temporary URI permissions, no persisted grant and provider descriptor
   accounting. Use the actual example and Send controls to commit G3; root and
   earlier stories stay unchanged. A repeated potion action rejects without
   advancing canon.
2. `hostileRetainedArchivesAndConflictsCannotMutateExistingStories`: select an
   unsupported future version and a checksum-valid retired-root hostile archive;
   neither yields confirmation or changes accepted stories. Validate a good
   archive and Cancel without importing. Import it explicitly, then refuse a
   same-ID import without overwriting any prior eligible views or catalog.

The test-only checksum encoder first matches an untouched native payload. It
does not make checksums authenticators. Canonical comparisons are assertions
inside the source-pinned test, not separately exported raw canonical sidecars
or proof of all hidden-world state. Provider descriptor accounting does not
establish a joined drain of asynchronous app adapters. OS death, power loss,
forensic erasure, ARM64, phone performance and real-model quality are separate.

## Consent provenance

Import confirmation, export picker launch and Open imported must carry the
exact immutable object rendered by the dialog. The controller checks reference
identity against its current prepared/imported object before any side effect,
in addition to kind, availability, picker, generation and single-use fences.
An older callback or an equal copied/foreign DTO cannot borrow a newer preview.
Kotlin supplies consent provenance; Rust still validates and commits canon.
