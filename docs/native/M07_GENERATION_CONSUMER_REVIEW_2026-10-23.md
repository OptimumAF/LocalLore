## Necessary correction boundary

A Host-only preread would leave a check/commit race. Root has proposed an opaque, native-only accepted-history basis captured from the coherent Work Engine, retained privately with the candidate, and checked inside Store's existing IMMEDIATE commit transaction. A bounded streaming digest of domain, scope/head, full Seed, private immutable lineage and exact original receipts avoids retaining another whole Engine for every Ready turn. It must not be deserializable, a Play/context metadata field, inspection grant, model data or another schema/ledger.

Finish should reject a changed basis early. Commit must independently recheck atomically before any new durable mutation. Preserve the existing exact recorded-outcome/idempotency semantics where the retained original Request and source permit them; do not turn late cancellation into claimed rollback. Stale/cancel/failure cleanup must also avoid writing a replacement source's identically keyed draft. Existing unbound public interfaces and historical receipts should not be silently reinterpreted as if they carried the new native basis. No such implementation was authored by this reviewer.
